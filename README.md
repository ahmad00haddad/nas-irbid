## 📖 عن المشروع
"ناس إربد" ليس مجرد موقع إلكتروني، بل هو أرشيف حيّ لذاكرة مدينة إربد الأردنية. نهدف إلى توثيق حكايات الناس العاديين، أصحاب المهن القديمة، والوجوه التي شكلت هوية المدينة، وتقديمها في قوالب وثائقية سينمائية مدعومة بتجربة مستخدم تفاعلية وعصرية.

## ✨ الميزات الأساسية
- **🗺️ خريطة الحكايات التفاعلية:** استكشف قصص المدينة جغرافياً عبر خريطة تفاعلية مدعومة بـ OpenStreetMap، مع نظام "عناقيد" (Clustering) ذكي للحلقات المتقاربة.
- **🎥 تجربة عرض سينمائية:** تصميم عصري يركز على المحتوى المرئي، مع تأثيرات حركية سلسة (Smooth Animations) وتجربة تصفح غامرة.
- **💡 تفاعلات دقيقة (Micro-interactions):** اهتمام بالغ بالتفاصيل النفسية والبصرية؛ مثل شريط تقدم القراءة، شطب الكلمات الحية، تأثيرات الإضاءة (Glow Effects)، وتلميحات مبنية على سلوك الزائر (مثل نية الخروج Exit Intent).
- **📊 الشفافية المالية:** قسم خاص يعرض بوضوح كيفية توزيع تكلفة الإنتاج لكل حلقة بنسب مئوية متحركة وشروحات تفصيلية، التزاماً بمبدأ "الدعم مسؤولية مجتمعية".

## 🛠️ التقنيات المستخدمة (Tech Stack)
تم بناء المشروع بأحدث تقنيات الويب لضمان أداء عالٍ وتجربة مستخدم احترافية:
- **إطار العمل:** React.js (Vite) + TypeScript
- **التوجيه (Routing):** TanStack Router
- **التصميم (Styling):** Tailwind CSS + Shadcn UI
- **الحركة (Animations):** Framer Motion
- **الخرائط:** React Leaflet
- **قاعدة البيانات (Backend):** Supabase

## 🚀 التشغيل المحلي (Getting Started)

لتشغيل المشروع على جهازك المحلي، اتبع الخطوات التالية:

1. **استنساخ المستودع (Clone the repo):**
   ```bash
   git clone https://github.com/ahmad00haddad/nas-irbid.git
   cd nas-irbid
   ```

2. **تثبيت الحزم (Install dependencies):**
   ```bash
   npm install
   # أو
   bun install
   ```

3. **إعداد البيئة (Environment Variables):**
   قم بإنشاء ملف `.env` في المسار الرئيسي وأضف مفاتيح Supabase الخاصة بك:
   ```env
   VITE_SUPABASE_URL="https://your_project_id.supabase.co"
   VITE_SUPABASE_PUBLISHABLE_KEY="your_anon_key"
   ```

4. **تشغيل المشروع (Run development server):**
   ```bash
   npm run dev
   ```
